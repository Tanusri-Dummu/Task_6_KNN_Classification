# Task 6: K-Nearest Neighbors (KNN) Classification

## 📌 Objective

The objective of this task is to understand and implement the K-Nearest Neighbors (KNN) algorithm for classification problems. The model is trained on the Iris dataset and evaluated using various performance metrics.

---

## 📂 Dataset

**Dataset Used:** Iris Dataset

The Iris dataset contains information about iris flowers with the following features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

Target Classes:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

---

## 🔄 Workflow

### 1. Data Loading

Loaded the Iris dataset and converted it into a structured format for analysis.

### 2. Data Preprocessing

Normalized the feature values using StandardScaler to ensure fair distance calculations in KNN.

### 3. Train-Test Split

Split the dataset into training and testing sets.

### 4. Model Building

Implemented the K-Nearest Neighbors Classifier using Scikit-learn.

### 5. Model Evaluation

Evaluated the model using:

* Accuracy Score
* Confusion Matrix

### 6. Hyperparameter Tuning

Tested multiple values of K (1–10) to determine the optimal number of neighbors.

### 7. Visualization

Created a graph to visualize the relationship between K values and model accuracy.

---

## 📊 Results

### Accuracy Score

The KNN model achieved high classification accuracy on the Iris dataset.

### Confusion Matrix

The confusion matrix was used to analyze prediction performance across all flower classes.

### K vs Accuracy Graph

The graph helped identify the most suitable K value for the classification task.

The K-Nearest Neighbors (KNN) algorithm was successfully implemented on the Iris dataset.
